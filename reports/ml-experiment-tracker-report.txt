Category: mlops

----------------------------------------------------------------------
DESCRIPTION
----------------------------------------------------------------------
Lightweight experiment tracking system. Log hyperparameters, metrics, artifacts. Compare experiments with Flask dashboard. SQLite-backed, zero-config.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - flask
  - pandas
  - matplotlib
  - click
  - pydantic
  - pytest

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * Log parameters, metrics, artifacts
  * Tag-based organization
  * Flask dashboard with charts
  * Metric visualization
  * CLI for listing/exporting
  * CSV/JSON export

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  Training run data

  Example:
    python cli.py experiments && python cli.py dashboard

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Experiment comparison

  Example:
    Best: accuracy=0.94 (run_3, lr=0.001, epochs=50)
